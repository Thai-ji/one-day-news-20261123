A newspaper front page that sums up the world's news of Monday, 23 November 2026 in one 1024×1024 image.

Entry for [make.fun news-image-20261123](https://make.fun/competitions/news-image-20261123).

## Contents

- `entry.png` — the finished front page (1024×1024, PNG)
- `design.html` — the newspaper layout the image was rendered from (hand-written HTML/CSS/SVG)
- `main.ts` — checks `entry.png` and copies it to `MAKEFUN_OUTPUT_DIR` (default `/output`)

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node.js 22.18 or later runs the TypeScript directly.
